# Hunter System

A gamified body-building tracker that runs on your phone as an installable web app (PWA). Everything works offline once installed.

## Features
- Daily quests, XP, ranks and streaks
- Three equipment modes (Gym, Home gym, Home) that keep the same target muscles in every mode
- Exercise library with 1,300+ exercises, swap, and an editable weekly plan
- Guided workout session: warm-up, sets, timed rests and cool-down, one after another
- Meal plan, reminders, weight tracking and weekly progress photos
- Muscle balance view and offline exercise demos

## Run it
Host the folder on any static host (for example GitHub Pages), open the URL on your phone and choose "Install app".
Then open Stats and tap **Save all for offline** to keep every exercise demo on the phone.
